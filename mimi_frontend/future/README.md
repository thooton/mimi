# Deferred prototype features

This directory preserves first-draft features that are intentionally excluded
from the active Astro application. Files here are reference material and are
not expected to build in their current locations.

- `practice/` contains the short-story and podcast/audio mockups, their
  marketing-page sections, navigation entries, and the original shared styles.
- `community/` contains the clubs, forums, chat-match pages, supporting code,
  profile club panel, and the original shared community/leaderboard styles.
